# 2025-07-20

## 上午

​	今天早上起床先把昨晚收拾好的这星期穿的所有衣服放到楼下的洗衣机里，用了3元的硬币，洗衣机用时显示是35分钟，实际是40分钟，可能最后5分钟是甩干吧。之后我就上楼洗漱，洗漱完泡了碗黑芝麻糊，这就是我今天的早饭。吃完黑芝麻糊，我看了眼时间还有15分钟才能洗完，我就拿起了我从大连图书馆借的一本书：《高情商交际学-掌控在交际中的主导权》。因为之前一直没看过，然后我就从第一章开始看，其中看到了作者对于交往的态度就是必须得有积极性，比自己地位高的攀不上，那就从跟自己地位差不多的人开始，积极、主动的交流才能够消除恐惧和猜测。还有就是成功之人的大门是虚掩的，不要怕接触成功人士，也不要有成功的人，时间都很宝贵，这种想法。要去积极想办法怎么才能去接触成功的人士，作者还引用了篇故事，有一户人家菜园里有块大石头很碍事，儿子问爸爸为什么不挪走，爸爸说爷爷那时就有了，石头应该很重，要不不可能不挪走，过了很多年儿子长大了，娶了媳妇，媳妇问他为什么石头不挪走，他说我小时候就有了，要是能挖走，早就没了。媳妇听了很不自在，于是自己就去尝试挖石头，结果挖着挖着很轻松的就挖出来了。这个故事就说明不要看着表面很遥远，要敢于去尝试，成功的人表面看起来是块大石头，但其实是因为你不了解，接触之后才会了解。

​	等洗完衣服，我就把衣服挂衣架上晾起来。穿上今天要穿的衣服，昨天晚上计划是上午去理发，理发店的位置在招商·海德学府，看着其实挺近的，我决定走走去，出了自动化的门口，我没像一如既往地那样往左转，而是选择了往右转，我觉得那边应该还会有路，而且还是近路，结果我到了，发现路都是死路，于是我又折返了回来，但我并没有觉得什么，而是我探索了未知，发现这条路走不通，那就换条能走通的路呗，虽然长了点儿，但是可以锻炼身体啊。走路的过程我还是离不开耳机，耳机一直循环着昨天看的《F1：狂飙飞车》电影的主题曲，感觉百听不厌。走了大概30多分钟，终于到地方了，这天实在太晒了，还潮，我出了一身汗，然后看到附近正好有间超市，我打算买瓶水解解渴，我看到超市门前就有冰柜，里面有很多饮料，但是我没有直接拿，而是进去问一下老板是在哪拿冰镇饮料，老板说就是超市门前的冰柜里，于是我先挑着想喝啥，看到了外星人海盐荔枝味的，还有大瓶，我觉得我这走了一身汗，可能会流失电解质，于是选了这瓶水。超市里开着空调，进去就觉得很凉快，舒服，就不想出去了，然后正巧有一个人，进来应该是拿快递，和老板也比较熟，聊了起来，趁他俩聊的间隙，因为我一直超市里站着，也没继续买东西，怕老板想我要干啥，于是我主动跟老板说：姨，我走了一身汗，在你这歇一会儿哈，她说：好的。后来那个拿快递的走了，老板让我坐在他之前坐的那个椅子上，但我觉得我还是站一会吧。后面又来了个人是想微信支付500元，然后换对应现金的，这也让我想起了我要换点儿硬币用于在宿舍里洗衣服，于是等他换完，我就跟老板说我要换20块钱硬币，老板同意了，给我每次按5个一组，4组，共计20个，老板说这个一般都不换的，现在也不好弄，我说对啊，现在都是微信支付，也没有用现金的了，我又跟老板聊了起来，我要去旁边的理发店理发，老板说她家确实不错，剪得很仔细，不糊弄，我说这样挺好，我之前去的理发店，看到有人来了，突然就加快了节奏，剪得就不好。又说到今天是入伏，老板说入伏得需要吃饺子啊，我还忘了这件事儿，我问她这周围有没有饺子馆，她说好像是没有，她说店里有速冻水饺，可以下着吃，但我在宿舍里没有锅，但我后面想了想，我那个在别的屋经常一起聊天的，他有个锅。我就决定进去挑了三袋饺子，看到了虾爬，虾仁、牛肉的。然后我拿出来找老板结账，因为我一会儿得去理发，这天气这么热，我就跟老板说，我先结账吧，然后这个放冰柜里，要不理发可能就花了，她说好的。然后我就去了旁边的理发店，理发店里人其实也少，但是老板跟我说是需要预约的，我也是第一次来，我问她啥时候能有空的，她说得下午四点，看来我这次是白来了一趟，老板让我加她微信，我就加了，然后我就跟她说了，那我就下午四点来了。之后我就回超市取了下饺子。然后就走回去了，路上还买了西瓜，西瓜是长条的，但卖西瓜的不想给我再切，我也没再要求，他让我先尝尝味道咋样，给我切了一小块，但我没拿住掉了，他又给我切了块，我吃了感觉还行，于是就要了，然后他看到我那瓶外星人饮料，他问我甜不甜，因为这个外星人饮料是0糖0卡的，用甜味剂代糖，但肯定还是有甜味的，我就跟他说，还行不算很甜。然后我有点儿拿不动，我就决定去等一等公交车，等了不一会，就来了辆205，我正好上去了，当时应该是9点40，我就打算把这个时间记上去，毕竟这块公交次数太少了，每次都得等很长时间，应该是一个小时或者半个小时一辆。到了飞马家具下的，车上还有一个人也下了，应该是加班的，毕竟在这下的很少。因为拿着西瓜和速冻饺子，我决定先去办公室，放冰箱里。进了办公室我也是很热，开了会空调，我竟然还坐着睡着了，等醒了时候，已经11点10分，想起食堂应该也有饭，虽然我没报加班，但是也能吃上。周末的中午食堂还是比平时晚上食堂的菜要多的。我选了两荤一素，是13元。吃饭时候，也不忘拿起手机，开了surfboard，看了维基百科，看了下随机条目，盖洛普最敬佩的人民意调查，应该是对于美国民众展开的最敬佩的人民意调查，我看到了艾森豪威尔的照片、奥巴马、希拉克·克林顿、埃莉诺·罗斯福（也是第一次看到，看名字应该是富兰克林·罗斯福的妻子），这里的人基本都是美国总统和美国第一夫人。然后罗斯福的妻子还是世界第一夫人，因为协助发布《世界人权宣言》。看完这些我就吃完了饭，决定先回宿舍取包。

## 下午

​	下午我计划回办公室，把要做的AI应用开发服务器的系统给切换到Ubuntu Server Linux，因为之前一直用的WSL On Windows 11，多少有点儿损失性能，而且还开不了外网端口映射，我打算如果有外网的话，我可以在宿舍的电脑上访问我部署好的模型API。于是我先打开我的电脑，从WSL把之前通过 sudo tar -zcvf 打好的tgz压缩包 download下来。然后都完事了，我就拿着我的u盘去往机房给重做了下系统，因为之前在虚拟机里做过Ubuntu 的Server版系统，觉得也没有什么压力。部署过程也还行，期间也发生了些预期之外的事，比如说在搜索硬盘分区时，卡了一会儿，我只好重新退出到第一步选择语言，重新进去，这次就没问题了，分区/boot给了2G，防止之后升级kernel空间不足需扩容的情况，剩余空间都给了/根分区，没有做/swap分区，因现有物理内存为64G，基本上不会出现swap的情况。
