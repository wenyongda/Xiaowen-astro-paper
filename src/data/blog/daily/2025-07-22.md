# 2025-07-22

## 上午

​	今天早上吃了两个茶蛋和一碗豆浆，其中一个茶蛋是真的烫手，只能拿到水槽用水龙头冲了冲，再扒开吃。吃完饭还真巧下雨了，只能跑着去办公室，淋了一身。上午我就还是把AI应用开发服务器的图形用户界面配置了一遍，刚开始把ubuntu-desktop安装上了，它会附带thunderbirld、firefox等软件，是通过snap的方式安装的，这证明apt方式安装的包也会触发snap安装，之前snap安装一直报错509，找不到CA证书，其实就是被墙了，解决方式是在我本地电脑的clash verge开启了局域网访问，再在AI应用开发服务器里配置SOCKS5代理即可。其中又认识了几个snap命令，如snap install 安装snap包管理的软件、snap remove协助snap包管理的软件、snap list查看snap包管理的安装好的软件。安装好ubuntu-desktop，又想尝试KDE Plasma，结果无论我使用tasksel、sudo dpkg-reconfigure sddm，都无法切换过去

![Snipaste_2025-07-21_08-24-48](https://rustfs.wenyongdalucky.club:443/astro-paper/Snipaste_2025-07-21_08-24-48.png)

我又把ubuntu-desktop给卸载了，其中用了

```shell
sudo apt remove -y --purge ubuntu-desktop
sudo apt-get autoremove
sudo snap remove thunderbird
sudo snap remove gnome-42-2204
sudo snap remove firefox
sudo snap remove gtk-common-themes
sudo apt-get remove gnome-tweak-tool
sudo apt-get remove gnome-shell
```

但还是切换不到KDE Plasma，我只能跟之前借给我HDMI转VGA的同事借了下转接线，到机房里看下显示器是否切换到KDE Plasma了，果然显示器是切换到的，可以证明是XRDP出的问题，我于是查询XRDP和KDE Plasma，最后加了这个配置就好了

```shell
echo "/usr/bin/startplasma-x11" > ~/.xsession
D=/usr/share/plasma:/usr/local/share:/usr/share:/var/lib/snapd/desktop
C=/etc/xdg/xdg-plasma:/etc/xdg
C=${C}:/usr/share/kubuntu-default-settings/kf5-settings
cat < ~/.xsessionrc
export XDG_SESSION_DESKTOP=KDE
export XDG_DATA_DIRS=${D}
export XDG_CONFIG_DIRS=${C}
EOF
```

不得不说KDE Plasma的桌面是真的好看，壁纸还可以通过内置在线下载，然后可玩性也很高，功能很多，设计上很像Windows，GNOME是像MAC OS。

​	体验完，产线组的一位同事找我帮他整之前给他弄得vs 2019 社区版激活问题的，同样也是因为服务器无法联网导致的问题，是项目中用到了个Nuget包，但是没联网，正常是无法从nuget源上进行下载的，于是我先用nuget.exe先把需要的nuget包下载到本地，然后在服务器的D盘上建立对应的文件夹`NuGetOfflinePackages`，并将nuget包包括层级结构，上传进去，并在vs2019中进行了配置Nuget源，相当于本地搭了个Nuget源。
